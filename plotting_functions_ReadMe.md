# PCIL Visualization Functions

The PCIL pipeline includes three functions for visualizing PCIL (+) lines and PCIL (+)/PCIL (-) pairs:

```text
plot_all_pcil_positive()
plot_best_pcil_positive()
plot_pcil_pairs()
```

These functions are intended to provide a visual summary of the introgression structure of lines identified through the PCIL selection pipeline.

```text
select_pcil_positive()
        │
        ├── pcil_positive
        │       ↓
        │  plot_all_pcil_positive()
        │
        └── best_lines
                ↓
        plot_best_pcil_positive()
                ↓
        select_pcil_negative()
                ↓
        plot_pcil_pairs()
```

The plots are primarily intended for **visual interpretation and comparison**. Exact introgression coordinates should always be confirmed using the underlying data in `pcil_data$introgressions`.

---

# 1. `plot_all_pcil_positive()`

`plot_all_pcil_positive()` visualizes the target-containing introgression blocks for **all PCIL (+) lines** identified for each target.

## Input requirements

The function requires the output of:

```r
select_pcil_positive()
```

For example:

```r
all_pcil_pos_plots <- plot_all_pcil_positive(
  pcil_pos_pcv = pcil_positives
)
```

The input object must contain:

```text
pcil_positives
│
├── pcil_positive
└── regions
```

`sel` does **not** need to be used in `select_pcil_positive()` to generate this plot.

---

## Plot interpretation

A separate plot is generated for each target.

```text
PCIL (+) 1   -----------------------------
PCIL (+) 2      ---------------------
PCIL (+) 3          ----------------

                    |     |
                     Target
```

In the plot:

- each horizontal segment represents the **target-containing introgression block** of one PCIL (+),
- the red vertical lines indicate the **start and end of the target region**; for small regions, they may appear as a single line.
- lines are ordered by the length of the target-containing introgression block.

The SampleID labels are intentionally omitted because this plot is designed primarily to visualize the overall distribution of introgression sizes across the PCIL (+) population.

---

## Output

The function returns a named list of `ggplot` objects, with one plot for each target.

```text
all_pcil_pos_plots
│
├── Region_1
├── Region_2
└── Region_3
```

Individual plots can be accessed using:

```r
all_pcil_pos_plots[["Region_1"]]
```
---

# 2. `plot_best_pcil_positive()`

`plot_best_pcil_positive()` provides a **genome-wide view of the introgression structure of the selected PCIL (+) lines**.

This visualization is intended for use after preferred PCIL (+) lines have been selected using:

```r
select_pcil_positive(
  ...,
  sel = N
)
```

---

## Input requirements

The function requires:

| Argument | Description |
| --- | --- |
| `pcil_pos_pcv` | Output from `select_pcil_positive()` containing `best_lines`. |
| `pcil_data` | PCIL genomic datasets generated by `load_pcil_data()`. |

For example:

```r
all_pcil_best_plots <- plot_best_pcil_positive(
  pcil_pos_pcv = pcil_positives,
  pcil_data = pcil_data
)
```

Because the function visualizes the selected PCIL (+) lines, the input must contain:

```text
pcil_positives$best_lines
```

and therefore `sel` must have been provided during PCIL (+) selection.

---

## Plot interpretation

A separate genome-wide plot is generated for each target.

Each row represents one selected PCIL (+), with chromosomes displayed across separate panels.

```text
             Chr01       Chr02       Chr03       ...

PCIL 1      ----          --      --------
PCIL 2        ---                  ------
PCIL 3                    ----     ----------
```

The plot displays:

- **gray chromosome backgrounds** representing the chromosome,
- **introgression segments** showing donor-derived genomic regions,
- **red vertical lines** indicating the target region,
- the **top-ranked PCIL (+)** highlighted in magenta,
- additional selected PCIL (+) lines shown in black.

Sample labels include:

```text
SampleID (Clan/Family)
```

and lines are ordered according to their PCIL (+) `Rank`.

This plot allows the user to visually compare both:

1. the introgression containing the target, and
2. residual donor introgressions elsewhere in the genome.

The visualization is therefore particularly useful for evaluating the genome-wide structure of the preferred PCIL (+) lines after selection.

---

## Output

The function returns a named list of `ggplot` objects:

```text
all_pcil_best_plots
│
├── Region_1
├── Region_2
└── Region_3
```

For example:

```r
all_pcil_best_plots[["Region_1"]]
```

---

# 3. `plot_pcil_pairs()`

`plot_pcil_pairs()` provides a genome-wide comparison between each selected **PCIL (+)** and its matched **PCIL (-)** candidate(s).

The plots are generated from the output of:

```r
select_pcil_negative()
```

and are intended to help evaluate the genomic similarity of proposed PCIL (+)/PCIL (-) experimental pairs.

---

## Input requirements

The function requires:


| Argument | Description |
| --- | --- |
| `pcil_data` | PCIL genomic datasets generated by `load_pcil_data()`. |
| `pcil_neg_sel` | PCIL (+)/PCIL (-) pairing table generated by `select_pcil_negative()`. |
| `pcil_pos` | Output from `select_pcil_positive()` containing the `regions` object used to define the genomic target. |


For example, when multiple negatives were requested:

```r
all_pcil_pair_plots <- plot_pcil_pairs(
  pcil_data = pcil_data,
  pcil_neg_sel = pcil_negatives$pairs_extended,
  pcil_pos = pcil_positives
)
```

A separate plot is generated for each:

```text
Target × PCIL (+)
```

combination.

The plot includes the focal PCIL (+) and its matched PCIL (-) candidate(s).

---

## Plot interpretation

Each plot shows the genome-wide introgression structure of one PCIL (+) and its associated PCIL (-) candidates.

```text
                    Chr01   Chr02   Chr03   ...

PCIL (+)             ---            ======
Best PCIL (-)         --              --
PCIL (-) #2                         ---
PCIL (-) #3            ---
```

The plot uses:

- **magenta** for the focal PCIL (+),
- **blue** for the highest-ranked PCIL (-) pair,
- **black** for additional PCIL (-) candidates,
- **gray chromosome backgrounds**,
- **red vertical lines** for the genomic target.

PCIL (-) lines are displayed according to their `Pair_Rank`, with the best PCIL (-) immediately following the focal PCIL (+).

The visualization can be used to evaluate:

- genome-wide similarities and differences in the genome-wide introgression structure of the PCIL (+) and PCIL (-)
- residual donor introgressions in the proposed negative controls,
- differences in introgression structure among alternative PCIL (-) candidates,
- and the genomic context of the target region.

---

## Important: interpreting introgressions near the target

The pair plots provide a **genome-wide visual summary**, and genomic positions are displayed at the Mb scale.

Because of this scale, an introgression in a PCIL (-) may occasionally appear visually very close to, or even appear to overlap, the red target lines.

This does **not mean that the PCIL (-) carries an introgression spanning the target**.

PCIL (-) status is determined from the underlying introgression coordinates used by the selection function, not from visual inspection of the plot.

If there is any uncertainty, the introgression structure of a line should be confirmed directly using:

```r
pcil_data$introgressions
```

For example:

```r
pcil_data$introgressions[
  pcil_data$introgressions$SampleID == "Sample_ID",
]
```

> The plot should be used for visualization, while `pcil_data$introgressions` should be used to confirm exact introgression boundaries.

---

## Output

The function returns a named list of `ggplot` objects.

Each plot name combines the target and focal PCIL (+):

```text
Region_SampleID
```

Conceptually:

```text
all_pcil_pair_plots
│
├── Region_1_PCIL_A
├── Region_1_PCIL_B
├── Region_2_PCIL_C
└── ...
```

An individual plot can be accessed using:

```r
all_pcil_pair_plots[[1]]
```

---

# Example visualization workflow

```r
# All PCIL (+)
all_pcil_pos_plots <- plot_all_pcil_positive(
  pcil_pos_pcv = pcil_positives
)

# Selected PCIL (+)
all_pcil_best_plots <- plot_best_pcil_positive(
  pcil_pos_pcv = pcil_positives,
  pcil_data = pcil_data
)

# PCIL (+) / PCIL (-) pairs
all_pcil_pair_plots <- plot_pcil_pairs(
  pcil_data = pcil_data,
  pcil_neg_sel = pcil_negatives$pairs_extended,
  pcil_pos = pcil_positives
)
```

The three visualizations provide complementary views of the PCIL selection process:

```text
All PCIL (+)
      ↓
Target introgression distribution
      ↓
Selected PCIL (+)
      ↓
Genome-wide introgression structure
      ↓
PCIL (+) / PCIL (-) pairs
      ↓
Genome-wide comparison of
experimental contrasts
```
